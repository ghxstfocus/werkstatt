# Skill-Creator

## Ablauf
1. Interview: Was ist die Aufgabe? Wann soll die Skill laden?
2. Draft: SKILL.md mit name, description, Inhalt.
3. Review: Passt die description? Ist der Inhalt 100-450 Woerter?
4. Publish: In skills/<name>/SKILL.md.

## Format
- description endet mit "Use when...".
- Inhalt ist konkret, nicht Prosa.
- Beispiele sind Pflicht.
