# Simplify

## Drei Perspektiven
1. Reuse: Gibt es existierende Utilities, die wiederverwendet werden koennten?
2. Quality: Ist der Code idiomatisch? Klar? Ohne Redundanz?
3. Efficiency: Gibt es offensichtliche Performance-Probleme?

## Review-Checkliste
- Keine duplizierten Code-Bloecke?
- Keine ungenutzten Variablen/Imports?
- Keine over-engineered Abstraktionen?
- Keine versteckten Seiteneffekte?
